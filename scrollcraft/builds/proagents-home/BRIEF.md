## The eight topics

1. **Vibe** — machine-native precision; the page behaves like the tool it sells.
   References: typesafe.ai (diagram-native, monospace module labels, the page
   computes real things), terminal culture. Not "sites you like": the named
   reference is a product-adjacent lab page.
2. **Journey** — recognition (your agent, present tense) → the gap (generic
   agent, no profession) → turn (equip: the pipeline compiles into your harness)
   → substance (the registry: manifest hydrates into JSON sections) → range
   (the catalog, real entries) → commitment (a working terminal).
3. **Energy curve** — calm open, focused tension, crisp turn, absorbed peak at
   the hydrator, lighter browsing at the catalog, confident close.
4. **Feeling** — familiar → doubtful → clear → absorbed → curious → ready.
   ONE moment: watching manifest.json hydrate into its JSON sections as you
   scroll — the product's own mechanic performed by the scrollbar.
5. **One thing no site does** — scroll progress hydrates a real file tree the
   way the CLI hydrates artifacts, with byte counts computed from the real
   manifest, not invented numbers.
6. **Range** — premium-minimal with diagram-native precision (the typesafe.ai
   lean), inside the ProAgents brand world.
7. **World** — distinct scenes (panels of an operating surface), hard cuts.
   Not worldflight: there is no geography.
8. **Assets** — none generated. The world is the product's own surface: real
   markup, real embedded registry data (catalog.json, security-engineer
   manifest.json). The illustrated/diagram world is honest here because the

## Grammar

**Live surface** (references/uniqueness.md §2.3). ProAgents is a CLI for coding
agents; the honest pitch is "watch what it does". Bans honored: no wordmark+CTA
marketing bar (nav is app chrome: a status bar), no scrims, no photography, no
kinetic headline stacks, no scrub, no spotlight, no 6rem section headings —
copy lives in the surface's idiom (status lines, log lines, labels, tooltip-ish
annotations). The close is an actual input: a working terminal computing over
the embedded real catalog. Honesty rule: the terminal and hydrator are real
markup computing from real embedded data, and the page labels the terminal as a
demo of the CLI.

Why the other seven lost: filmic one-shot is the default drift (and banned by
the grammar's own burden of proof); chaptered editorial reads like documentation,
which the docs site already is; continuous world has no geography; typographic
poster fits a brand whose asset is a sentence — ProAgents' asset is a working
system; gallery/catalog fits a range, not an argument; split stage fits two-side
arguments; worldflight is for journeys through places.

## Signature move

**The hydrator.** A pinned act renders the real security-engineer manifest.json
as a file tree; act progress hydrates section folders one by one (empty →
populated paths), with a hydration percentage and a byte counter computed from
the real per-section path counts. CSS drives it from `--sc-p`; bespoke JS only
maps p to per-section thresholds (no engine edits).
